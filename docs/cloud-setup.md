# 微信云开发、腾讯 OCR 与腾讯地图配置

截图识别和机场—酒店驾车时长由云函数完成。密钥绝不能写入小程序源码或提交到 GitHub。

## 1. 开通微信云开发

1. 在微信开发者工具顶部点击“云开发”，为当前 AppID 创建一个云环境。
2. 等待环境初始化完成后重新编译项目。`wx.cloud.init()` 默认使用当前关联环境。
3. 在开发者工具资源树中找到 `cloudfunctions` 文件夹。

## 2. 配置腾讯云 OCR

1. 在腾讯云控制台开通“文字识别”，并确保账号有调用 `GeneralAccurateOCR` 的权限。
2. 为云函数准备最小权限的腾讯云 API 密钥。不要使用账号主密钥。
3. 在 `analyzeOrder` 云函数的环境变量中配置：
   - `TENCENT_SECRET_ID`
   - `TENCENT_SECRET_KEY`
   - `TENCENT_OCR_REGION`（可选，默认 `ap-guangzhou`）
4. 在开发者工具中右键 `analyzeOrder`，选择“上传并部署：云端安装依赖”。

订单截图最大 7MB。图片只临时上传，OCR 完成后云函数会删除原图；小程序仅保存用户确认后的结构化字段。

## 3. 配置腾讯地图

1. 在腾讯位置服务控制台创建应用和 WebService API Key，开启地址解析与驾车路线规划能力。
2. 建议为 Key 设置适合云函数调用的服务端限制，并按腾讯位置服务要求配置配额或签名校验。
3. 在 `routeDuration` 云函数的环境变量中配置 `TENCENT_MAP_KEY`。
4. 右键 `routeDuration`，选择“上传并部署：云端安装依赖”。

小程序会识别时间线上相邻的“航班到达机场 → 酒店”和“酒店 → 航班出发机场”，自动计算驾车时长并缓存到旅行数据中。地点变更后会重新计算。

## 4. 验证

1. 打开示例旅行，点击“截图导入”。
2. 上传一张订单截图，核对识别类型及字段后点击“确认并加入行程”。
3. 当酒店与机场在时间线上相邻时，详情卡片下方应出现“驾车约 N 分钟”。
4. 若识别结果不完整，应在确认页手动修正；程序不会在未经确认时直接写入行程。

## 安全说明

- `.gitignore` 应持续排除本地私有配置和密钥文件。
- 云函数环境变量属于运行时配置，不应写进 `project.config.json`。
- 正式上线前应增加调用频率限制、用户额度、费用告警和敏感字段脱敏日志。
